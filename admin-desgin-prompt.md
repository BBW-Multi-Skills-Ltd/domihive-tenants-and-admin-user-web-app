5) The real admin workflow (end-to-end)

Here’s your business in one flow:

Step 1: Onboard Client

Create client profile → add bank details → mark “Verified client”.

Step 2: Create Contract

Attach contract to client → set terms → set dates → set management fee → set maintenance wallet rules.

Step 3: Add Property (building)

Tie property to client + contract.

Step 4: Add Units

Add units under property:

rent/caution per unit

bedroom/bath/size per unit

Step 5: Publish Units to Home/Browse

Home/browse should list available units (not just building).

Step 6: Inspection booking

Tenant books inspection for a unit → admin verifies attendance.

Step 7: Application approval

Approve/reject within 72 hours.

Step 8: Move-in confirmation

Admin confirms move-in → unit becomes Occupied → tenant gets My Properties.

Step 9: Bills + Rent renewals

Admin can create bills per unit and set rent renewal due dates.

Step 10: Owner reporting/payout (later)

Monthly/quarterly payout statements.
